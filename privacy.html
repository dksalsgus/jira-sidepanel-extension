Privacy Policy

Last updated: June 17, 2026

Important: Please Be Done does not collect or store personal data on any external server.

1. Information Stored

This extension stores only the following information in local Chrome storage:

  • Jira domain URL
  • Jira user email
  • Jira API Token
  • Display preferences, such as floating panel visibility settings
  • Cached Jira issue data, such as issue keys, summaries, statuses, priorities, issue types, parent issue information, and update timestamps

This information is used only to connect to your Jira instance, display your assigned issues, remember extension preferences, and keep the panel usable between refreshes.

2. Data Storage

All data is stored only in your browser's Chrome storage, including chrome.storage.sync and chrome.storage.local where applicable.

  • No data is sent to a separate server
  • No data is shared with third parties
  • The developer cannot access your stored Jira credentials

3. Network Requests

The extension sends requests only to the following domains:

  • The Jira instance configured by the user, for example *.atlassian.net

4. Cookies and Tracking

This extension does not use cookies and does not track users.

5. Data Deletion

You can clear stored credentials at any time from the extension settings.

All extension data is removed automatically when the extension is uninstalled.

6. Changes

This privacy policy will be updated if the extension's data handling changes.

7. Contact

For privacy-related questions, please open an issue in the GitHub repository.
